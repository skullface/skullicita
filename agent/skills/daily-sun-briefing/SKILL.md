# Daily sun briefing

1. Call `get-daily-uv-and-sunset` (follow the shared location rules in instructions).
2. Reply with today's peak UV index and sunset time in plain language.
3. Optionally note a short UV caution (e.g. 0–2 low, 3–5 moderate, 6–7 high, 8–10 very high, 11+ extreme).
